# Make Interfaces Feel Better

[![skills.sh](https://skills.sh/b/jakubkrehel/make-interfaces-feel-better)](https://skills.sh/jakubkrehel/make-interfaces-feel-better)

An [Agent Skill](https://docs.anthropic.com/en/docs/claude-code/skills) based on the article [Details that make interfaces feel better](https://jakub.kr/writing/details-that-make-interfaces-feel-better). It teaches AI coding assistants the small design engineering details that compound into a great interface — wrapping, radii, animations, alignment, shadows and more.

## Install

```bash
npx skills add jakubkrehel/make-interfaces-feel-better
```
